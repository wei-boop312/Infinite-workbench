# AI 电商视觉无限画布

阶段 1 可靠画布内核和阶段 2 资产、约束及存储安全边界已完成；阶段 3 正在建设统一任务、批次与成本内核。默认只运行假执行器，不连接模型、不读取供应商密钥、不产生费用。

## 目录

- `apps/web`：React + React Flow 画布。
- `apps/api`：项目、资产、预算与任务入口骨架。
- `apps/worker`：模型 API 与 MCP 执行器进程骨架。
- `packages/contracts`：跨进程数据合同。
- `packages/canvas-schema`：画布文档版本与迁移器。
- `packages/testing`：假执行器和故障测试夹具。
- `tests/e2e`：真实浏览器的鼠标、触控、500 节点、离线恢复和零外部请求检查。

## 当前能力

- 撤销、重做、内部复制粘贴、删除。
- 图片资产占位节点、可编辑文字节点。
- 多选建立分组、解散分组，父子关系写入 v2 画布文档。
- 图片、文字、约束端口声明数据类型；不兼容、重复和循环连接在落图前被拒绝。
- 自动整理按工作流依赖重排顶层节点，保持分组内子节点相对位置。
- 650ms 防抖自动保存、单调递增修订号与刷新恢复。
- 双标签页乐观并发检查；冲突时可另存当前修改或载入另一标签版本。
- 项目草稿彼此隔离；离线外壳支持断网重载，保存失败可重试或下载恢复文件。
- API 提供带 `If-Match` 条件修订的画布读写合同，为阶段 2 云端持久化预留冲突语义。
- 无版本/v1 画布自动迁移到 v2，未来版本拒绝加载。
- 浏览器使用轻量合同校验入口；服务端保留完整校验，避免把不必要的校验库带进首屏。
- 支持本地图片和视频导入，原文件与轻量预览保存在 IndexedDB，画布只保存 `assetId`。
- 32 MB 以内媒体使用完整 SHA-256 指纹去重；同一项目重复导入会复用资产，避免重复占用存储。
- 资产库按项目隔离，可把同一资产多次放入画布而不复制二进制。
- 约束节点可以冻结商品/品牌锁定项、可编辑区域、可选蒙版资产、品牌规则和输出规格。
- 约束快照不可变；每次调整创建新版本，后续任务只能引用明确的 `constraintSnapshotId`。
- 可在商品底图上使用画笔、矩形、多边形、套索和橡皮绘制透明 PNG 蒙版；蒙版编辑器拥有独立的 8 步撤销/重做，每次保存创建独立蒙版资产版本。
- 资产库显示项目占用和浏览器配额；画布、蒙版来源或历史约束仍在引用的资产禁止删除。
- 支持逐个移除或批量清理未使用资产，并在执行前再次确认。
- 支持把当前画布、原始媒体、预览、蒙版和全部约束快照导出为单个 `.canvaspack` 项目包；二进制媒体保持 Blob，不转成 Base64。
- 项目包导入前验证格式、长度、原文件和引用完整性，导入时创建独立项目副本并重新映射内部编号，不覆盖现有项目。
- 导入采用原子资产事务与失败回滚；导入项目会进入项目选择器并在刷新后恢复为上次打开的工作台。
- 定义可替换的对象存储接口；当前 IndexedDB 实现明确标记为“本地假远端”，用于零费用验证上传协议。
- 原文件按固定分片备份，支持暂停、继续、失败重试和异常退出后的会话恢复；已成功分片不会重复写入。
- 32 MB 内资产使用完整 SHA-256，超大资产使用固定分片 SHA-256 树指纹；不同项目的相同内容只保存一个假远端对象。
- 资产库显示逐项备份进度、失败原因、已备份/已复用状态和假远端实际占用，全流程不发起外网请求。
- 本地原文件丢失时，可从已完成的假远端分片备份恢复；恢复前重新校验分片摘要，恢复后保留原 `assetId`，画布与约束引用无需改写。
- API 具备默认关闭的对象存储签名网关合同；上传/下载凭证绑定租户、项目、资产、权限、有效期和单次使用状态。
- 服务端拒绝匿名签名、跨租户对象探测、只读成员上传、过期或篡改凭证，以及大小、MIME 或 SHA-256 不一致的上传。
- 当前签名网关仍为进程内假实现，不连接 S3、R2、OSS；完整边界说明见 `docs/object-storage-security-boundary.md`。
- 阶段 3 支持创建待确认批次；用户动作幂等键可恢复原批次，并拒绝同一幂等键下的参数漂移。
- 预计成本由服务端假定价器计算；人工确认必须匹配金额和币种，同时通过批次上限、项目预算和 `run:confirm` 权限检查。
- 确认后才冻结预算并按预期输出数量创建独立假任务；重复确认不会重复冻结或创建任务。
- 取消排队批次会取消未开始任务并释放预留；账本和审计采用追加记录，完整规则见 `docs/run-batch-cost-kernel.md`。
- 可控假调度器支持成功、部分失败、明确失败、慢任务超时和计费未知，并执行最大并发限制。
- 成功结果逐任务保留；超时不自动重试，人工重试创建带 `retryOf` 的新任务并重新检查成本。
- 假实际成本结算后立即释放估价差额；计费未知继续占用预留并禁止重试或取消。
- 任务内核支持可选的版本化状态存储；批次、任务、预算、账本、审计、预留和幂等索引可在服务重启后恢复。
- 文件状态存储使用同目录临时文件原子替换；损坏、预算配置漂移或金额不守恒的快照会被拒绝，不会静默清空。
- 重启时，排队任务保持排队；中断前仍在运行的任务转为 `billing_unknown`，继续占用预留且不会自动重试。
- 执行器先领取带编号和到期时间的任务租约，再凭当前租约启动；错误执行器或旧租约不能执行任务。
- 未启动租约到期后安全回到队列；已启动任务的租约到期则进入 `billing_unknown`，避免盲目重复调用供应商。
- 调度同时执行项目级并发、供应商适配器级并发和时间窗口启动限流，限流原因与建议重试时间写入返回值和审计。
- `billing_unknown` 由独立核账权限处理；核账人必须提交动作编号、预留快照、币种和外部证据引用。
- 确认已扣费时按核实金额结算并释放差额，确认未扣费时释放全部预留；两种结果都不会自动重试。
- 核账动作幂等且不可反向覆盖；实际扣费超过预留时保持冻结并升级处理，不会为了消除告警而伪造入账。
- 画布提供“任务与预算”面板：选择商品图和保存的约束、查看预估、人工确认、分段执行、单项重试、人工核账，以及结果回到画布。
- 本地开发工作台通过固定同源接口连接上述任务内核；项目默认模拟预算 ¥100，每个输出预估 ¥0.25、成功结算 ¥0.20，真实费用始终为零。
- 开发桥接核对输入、约束和蒙版底图归属；已登记快照不可覆盖，创建、确认与重试都执行输入校验。正式 API 仍需注入权威资产校验器，不能直接复用浏览器登记作为可信来源。
- 任务历史引用会保护原图资产；模拟结果只保存任务来源和锁定谱系，不伪造图片文件或资产编号。任务与预算响应不进入离线缓存。

## 命令

```text
pnpm install
pnpm dev
pnpm check
```

打开本地工作台后，先“导入资产”，再“＋ 约束”并保存快照，最后打开“任务与预算”。当前默认执行器仅模拟图片精修，视频节点仍可管理但不能生成。

开发桥接只在 Vite 开发服务器启用，要求回环主机、同源和 `x-canvas-local` 请求标记；随机内部身份令牌只存在服务端。状态保存在被 Git 忽略的 `work/local-studio-state/`，可用 `CANVAS_STUDIO_STATE_DIR` 指定单独目录。测试使用独立临时状态目录，不污染日常工作台。纯静态生产构建没有此服务；任务面板会明确报错而不会假装执行。

## 红线

- `apps/web` 不保存或读取供应商密钥。
- 浏览器不持有云存储密钥，也不能自行决定租户对象路径。
- 画布文档禁止媒体 Base64，只允许 `assetId`。
- API 与 MCP 共用任务、预算、审计和资产回流合同，但执行器彼此隔离。
- 生成谱系不可编辑；画布工作流边不能充当审计记录。
- 真实付费请求必须经过服务端人工确认与预算检查。
- 未完成假执行器的超时、部分失败和结算回归前，不开放真实供应商执行器。
