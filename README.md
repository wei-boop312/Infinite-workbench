# AI 电商视觉无限画布

阶段 1 可靠画布内核已完成；阶段 2 正在建设本地优先的资产与约束系统。默认只运行假执行器，不连接模型、不读取供应商密钥、不产生费用。

## 目录

- `apps/web`：React + React Flow 画布。
- `apps/api`：项目、资产、预算与任务入口骨架。
- `apps/worker`：模型 API 与 MCP 执行器进程骨架。
- `packages/contracts`：跨进程数据合同。
- `packages/canvas-schema`：画布文档版本与迁移器。
- `packages/testing`：假执行器和故障测试夹具。
- `tests/e2e`：真实浏览器的鼠标、触控、500 节点、离线恢复和零外部请求检查。

## 当前能力

- 撤销、重做、内部复制粘贴、删除。
- 图片资产占位节点、可编辑文字节点。
- 多选建立分组、解散分组，父子关系写入 v2 画布文档。
- 图片、文字、约束端口声明数据类型；不兼容、重复和循环连接在落图前被拒绝。
- 自动整理按工作流依赖重排顶层节点，保持分组内子节点相对位置。
- 650ms 防抖自动保存、单调递增修订号与刷新恢复。
- 双标签页乐观并发检查；冲突时可另存当前修改或载入另一标签版本。
- 项目草稿彼此隔离；离线外壳支持断网重载，保存失败可重试或下载恢复文件。
- API 提供带 `If-Match` 条件修订的画布读写合同，为阶段 2 云端持久化预留冲突语义。
- 无版本/v1 画布自动迁移到 v2，未来版本拒绝加载。
- 浏览器使用轻量合同校验入口；服务端保留完整校验，避免把不必要的校验库带进首屏。
- 支持本地图片和视频导入，原文件与轻量预览保存在 IndexedDB，画布只保存 `assetId`。
- 32 MB 以内媒体使用完整 SHA-256 指纹去重；同一项目重复导入会复用资产，避免重复占用存储。
- 资产库按项目隔离，可把同一资产多次放入画布而不复制二进制。
- 约束节点可以冻结商品/品牌锁定项、可编辑区域、可选蒙版资产、品牌规则和输出规格。
- 约束快照不可变；每次调整创建新版本，后续任务只能引用明确的 `constraintSnapshotId`。
- 可在商品底图上使用画笔、矩形和橡皮绘制透明 PNG 蒙版；每次保存创建独立蒙版资产版本。
- 资产库显示项目占用和浏览器配额；画布、蒙版来源或历史约束仍在引用的资产禁止删除。
- 支持逐个移除或批量清理未使用资产，并在执行前再次确认。
- 支持把当前画布、原始媒体、预览、蒙版和全部约束快照导出为单个 `.canvaspack` 项目包；二进制媒体保持 Blob，不转成 Base64。
- 项目包导入前验证格式、长度、原文件和引用完整性，导入时创建独立项目副本并重新映射内部编号，不覆盖现有项目。
- 导入采用原子资产事务与失败回滚；导入项目会进入项目选择器并在刷新后恢复为上次打开的工作台。

## 命令

```text
pnpm install
pnpm dev
pnpm check
```

## 红线

- `apps/web` 不保存或读取供应商密钥。
- 画布文档禁止媒体 Base64，只允许 `assetId`。
- API 与 MCP 共用任务、预算、审计和资产回流合同，但执行器彼此隔离。
- 生成谱系不可编辑；画布工作流边不能充当审计记录。
- 真实付费请求必须经过服务端人工确认与预算检查。
