## HTTP 与工作台

GET `/v1/projects/:projectId/generated-assets/:assetId/lineage` 必须显式配置读取端口；默认 503，匿名 401，越权/未知 404，完整性损坏固定 503。拒绝其他方法、查询、正文、Range；JSON 严格解析并核对租户/项目/资产编号，上限 512 KiB，private/no-store、Vary Authorization、nosniff、same-origin CORP/no-referrer，无跨域放行或签名 URL。日常开发桥接显式启用只读谱系，健康标记不是生成授权，本机模拟身份不是生产会话。

工作台只有原生图片实际单个 outputAssetId 的任务能点击“只读核验输出 N 谱系”。唯一 runClient 同源 GET/no-store/禁止重定向/本地标记，512 KiB/4096 非空分片/30 秒取消。浏览器核对实际批次/任务/项目/输出/原输入/确认/币种，重新计算冻结约束 SHA；坏响应或撤权不采用旧缓存替代。展示原设计/锁定/品牌/可编辑区/原输入/输出/确认及费用关系，明确这是本地假响应产物，不是真实供应商生成。

关闭面板/项目切换/StrictMode 旧回调取消并隔离；再次核验先清旧视图，撤权不留本次授权展示。已有获准下载的本机原文件不私自删除，不宣称撤权能销毁离线副本。本步骤不改画布/项目包、不写 Base64/临时 URL/令牌，不开放普通 generated 添加或旧 mock 原生回流。
