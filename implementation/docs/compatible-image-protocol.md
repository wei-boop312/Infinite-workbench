# 阶段 4 里程碑 3：兼容中转差异配置

日期：2026-10-03。实现范围是**服务器管理的严格差异合同、纯请求构造、本地假响应**。没有连接真实中转站、获取模型权限/价格、读取密钥或开启付费生成。

## 差异合同

`ImageCompatibilityProfileSchema` 只适用于 `openai-compatible` 连接，完整纳入人工确认摘要：

- 显式配置版本、生成/编辑相对端点；路径不能是跨站 URL、查询、片段、编码转义或穿越路径。组合地址保留 Base URL 的 API root，不能被前导 `/` 重置。
- 编辑格式固定选择 `json-images`、`multipart-image-array` 或 `multipart-image-single`；生成仍为 JSON。单图表单遇多参考图拒绝，不能默默丢弃输入。
- 鉴权计划为 Bearer 或三种受控头（`x-api-key` / `api-key` / `x-access-token`）；只关联服务端凭证引用。没有原始凭证、任意头模板、脚本、动态代码或查询参数密钥。
- 额外参数按整数范围、字符串枚举、布尔型和可用操作声明，最多 16 个；`0` / `false` 不会丢失。客户端不能覆盖模型、提示词、输出数、尺寸、蒙版、格式、流模式、鉴权或原型属性。
- 响应只声明 `images-b64-json-v1`。未知异步任务包、URL 下载或不同计费包需要独立适配，不在本里程碑猜测解释。

阶段 0 的旧连接合同不变；新的兼容连接如果没有差异配置，协议准备阶段明确拒绝。公开视图不暴露地址、凭证引用或差异配置；“配置/连通正常”不表示已经确认图片编辑能力，模型列表诊断不能升级能力证据。

## 请求构造与保护

`apps/api/src/compatibleImageProtocol.ts` 校验租户、项目、模型、报价和能力，再经共用 `imageRequestPayload.ts` 检查权威原文件、完整解码、EXIF/sRGB/PNG 归一化、蒙版和转换大小。官方模块复用同一实现，但保留自己的协议和最多 16 张引用约束，未为中转篡改官方模型或伪造官方连接。

兼容模型的蒙版极性须明确声明为透明编辑或白色编辑，转换版本及发送摘要分别记录；未核对或不支持蒙版即拒绝。两种极性通过本地像素测试，但**真实供应商行为尚未验收**；商品硬像素锁保护仍未配置，保持拒绝。

多段表单使用确定性边界、固定字段与合成文件名（不转发用户文件名/磁盘路径），逐块检查大小后再拼装。没有盲目重定向、请求发送、密钥解析、SDK 重试、协议降级或模型切换。请求/格式/鉴权/白名单改变，即使复用连接修订也会改变确认摘要。

响应复用严格 Base64/格式/魔数与用量检查；缺用量不是零收费，错误、429、超时与断线均保持计费未知。成功解析仍是待完整验证的候选字节，不是已经落库的资产或成功任务。

## 资料与测试

使用 OpenAI Docs 工作流重新实际打开[官方图片指南](https://developers.openai.com/api/docs/guides/image-generation)的多段表单示例和[编辑参考](https://developers.openai.com/api/reference/resources/images/methods/edit)的 JSON 合同，分别建立两种明确路径；这些资料**只证明官方基线，不能证明任意中转站兼容**。没有替用户选中转站、模型或真实价格。

新增 16 项本地差异/整合测试，包含真实回环 HTTP 服务和原生 FormData 解析，覆盖白名单、受保护参数、字段/文件名、两种蒙版极性、确认漂移、单图拒绝多输入、大小边界、未知响应、超时/429 无自动重试。

首次测试发现生成专用夹具仍声明编辑蒙版，已修正；同时发现 Zod 会忽略特殊对象键，新增原始键预校验并拒绝 `__proto__` 等字段，避免悄悄丢弃参数。两项失败修复后重新完整验证，不计为首次通过。

最终 `pnpm check`：23 个测试文件、167 项单元/集成、6 个工作区构建、29 项真实 Chrome 回归通过；底层编码保护与泛型测试夹具调整后全套重新跑过。浏览器仍无真实供应商入口，健康检查和原有画布/任务流程保持通过。

## 未实现与授权边界

- 凭证加密/解析、真实中转健康诊断、生产 HTTPS 传输、有界网络接收、SSRF/DNS/重定向策略未验收。这里的 URL/路径检查只是语法与组合边界，**不是完整 SSRF 防护**。
- 未提供任意鉴权头、任意 JSON 字段名、远端图片 URL 下载或异步任务协议；不得把少量明确格式宣称为“任意中转兼容”。
- 没有连接目录和画布选择界面、真实输出完整校验/锁区保护/持久化、真实费用结算或事务任务整合；测试内存幂等不是生产 Worker。
- 真实执行固定关闭，服务仍只用本机 mock，`realExecutorsEnabled=false`。测试状态隔离，未改用户工作台数据或重启既有 5173 服务。
