# 阶段 4 里程碑 5B4A：供应商选择与未确认假报价界面

日期：2026-10-04（上海）。本文记录 **5B4A 的历史本地验收**，范围为供应商目录、明确模型/操作/参数选择、本地假报价准备和历史恢复。当时没有人工确认/预算预留按钮；后续 5B4B 界面与严格只读确认恢复见 `image-confirmation-ui.md`，仍没有供应商生成执行或真实接通。日常目录仍默认空，不种入模型、价格或诊断，不读取私人密钥。

## 公开能力与网络边界

原目录只公开模型名称/操作标签，不足以可靠选择参数。本轮新增严格 ImageProviderPublicSchema / ImagePreparationPublicSchema，公开每模型的尺寸、格式、质量、背景、输入限制、保真/压缩和蒙版极性，以及兼容中转允许的枚举/整数/布尔参数规则。公开规则不包含端点、鉴权方案、凭证引用或 Google 私有协议映射；Base URL / credentialRef 继续隐藏。未知字段、假授权和不一致的公开准备关系失败关闭。

模型声明、诊断、本地假响应证据及真实请求证据分别显示；目录读取/准备成功不是实际生成或编辑能力验收。自定义协议没有适配器，停用连接和自定义协议不可选择。供应商、模型、操作、约束、质量和背景须人工明确选择，不选择列表第一项或偷偷换模型。目录修订或能力变化会清空当前显式选择，旧准备单仍作为历史显示。

新请求仍只通过 runClient 唯一固定同源边界，带本地标记、no-store、禁止重定向和同源凭证策略。目录 JSON 上限 2 MiB，单准备响应 512 KiB，最多 4096 个非空分片、30 秒取消信号；校验实际流大小、UTF-8/JSON、响应类型和 no-store。客户端容量是本机界面边界，超限整体拒绝，不截断目录或偷偷省略能力；不是生产全局资源限制。POST 准备体限 128 KiB，字段仍来自严格选择合同，浏览器不能自写报价、授权、任务、收据或发送摘要。

## 人主导选择与原文件

输出尺寸/格式来自选定的不可变人工约束，参数区不修改约束。每份准备 n=1；可选择供应商声明的自动尺寸，但产物仍须符合人工输出约束，不保证供应商默认尺寸就合格。质量、背景、输入保真和压缩只接声明范围；中转额外参数由受控规则生成输入框，不提供任意 JSON/脚本或任意字段覆盖。

编辑需逐张人工选择，选中顺序即输入顺序，首张为蒙版底图。蒙版须同时匹配人工约束、声明能力/已核对极性、真实底图及尺寸；多蒙版、不支持或极性未核对均拒绝，不自动忽略。上传前检查声明的字节/像素/数量/格式及本机原文件是否存在；实际发送的是 IndexedDB original，不是代理缩略图。原图先在本机权威服务完整核验，蒙版随后核验，前后端服务仍是最终权限/政策权威；浏览器检查不是资产收据或执行授权。

product.pixels / pixel-exact 仍不可承诺；界面明确拒绝，不改锁、缩图、静默降级或自动重试。输出 >1600 万像素或单边 >8192 在准备前拦截；4096×4096 即使模型声明支持也不能绕过本机政策，自动尺寸也不绕过。品牌/可编辑规则保持原约束，真实锁区保护尚未验收。

项目切换时 App 的异步资产/约束数组可能暂留旧项目，本轮在 RunPanel 按项目过滤后登记，避免把旧项目数据以新项目编号提交；服务端上下文仍追加合并，不删除现有目录、原图、任务或约束。关闭面板/切换项目取消请求，React StrictMode 的旧异步回调也不能更新新客户端/项目。

## 准备与恢复不是执行

保存结果固定 unconfirmed / executionAuthorized=false / protocolPreparation=not-run，显示明确的币种、整数最小币种单位、假估价/上限、版本/证据/有效期、完整冻结请求模板及摘要。没有任务编号、预算预留、费用结算或确认执行按钮；不复用旧 mock 自动成功/已知费用路径。

浏览器按项目在 localStorage 保存**最后一个恢复指针**：严格选择、原动作编号，以及收到的准备单编号。包含设计指令/选定资产编号，是本机设计数据，不含地址、凭证、报价或授权；不写画布/项目包，不是正式多租户离线隔离。服务端仍保留全部历史，浏览器指针不是第二个权威账本。

在任何 POST 前保存指针，存储失败即停止，避免生成不能追踪的新动作。成功后写入返回编号；若后写失败，界面仍显示服务端编号，原动作指针可用于人工恢复。刷新/重新打开只在已有编号时 GET 原历史；响应不明、坏合同或错配时不会自动 POST，而是提供“人工恢复原准备动作”，严格使用原选择和幂等键，不采用已改表单。

历史恢复不重新报价，过期/连接停用仍展示原未授权历史。修改参数/连接/报价或新准备，须明确“开始新准备动作（保留服务端历史）”，只清除本项目浏览器恢复指针，下次用新动作编号。损坏/跨项目/含假报价或授权的指针失败关闭，必须明确处理，不静默覆写；人工按编号读历史也不授予确认。网络/取消/权限/校验失败均无伪成功节点，不改任务/预算/未知费用预留。
