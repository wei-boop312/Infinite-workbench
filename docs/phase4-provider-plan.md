## 官方资料核对带来的设计边界

OpenAI 的 Image API 提供生成和编辑端点；Responses 还可以通过图像工具生成。本工作台先设计显式图片端点，避免把不同协议混成一个“万能聊天接口”。蒙版仅引导模型，不保证精确边界，因此不能把模型接受蒙版当作商品像素锁定的证据。[官方图片指南](https://developers.openai.com/api/docs/guides/image-generation)

当前编辑参考支持图片/蒙版引用、多个模型与各自参数；返回图片可包含 `b64_json`，`usage` 可选。不能假设每个兼容中转都返回相同内容或用量，也不能依赖服务端默认模型。[官方编辑 API](https://developers.openai.com/api/reference/resources/images/methods/edit)

未确定用户的具体供应商、模型权限与价格，不在准备阶段替用户选定付费模型。资料核对采用 OpenAI Docs 工作流，未读取 API Key；当前没有可用的专用 API Key 工具，也没有调用真实端点。

## 有限实施里程碑

1. **能力、参数与结果合同**：声明协议、显式模型、生成/编辑/透明输出/蒙版能力、尺寸与输入限制；服务端拒绝不支持参数。连接状态区分未配置、配置有效、诊断有效、假响应通过、真实请求验收，不能只显示“连接成功”。默认禁用真实执行。
2. **官方协议与本地假响应**：优先实现显式图片生成/编辑请求和严格返回解析，每个 RunJob 只请求一个输出，保留请求编号、输入摘要、约束与参数版本。无外网、固定假凭证、注入本地测试传输，验证超时、重复响应、缺用量、损坏产物等情况。
3. **兼容中转差异配置**：Base URL、鉴权方案与允许的额外参数由服务端管理；协议差异声明而非任意代码执行。JSON/多段表单、返回格式与能力逐项校验，不把能列模型当成能编辑图片。
4. **非 OpenAI 协议适配**：核对选定供应商的当时官方文档，用同一能力/任务/结果合同转换其原生请求。没有蒙版或硬约束能力时明确拒绝对应工具，不静默退化为整图随机生成。
5. **画布、成本与真实资产回流**：画布工具可换适配器而不改画布数据模型；输入使用已验证原文件。响应必须经过有界解码、MIME/魔数/尺寸检查后保存真实资产与不可变谱系；不把假编号或供应商 Base64 放进画布。
6. **专项验收与授权关口**：完整本地单元、集成、浏览器及故障回归通过后，真实最低成本请求必须另获用户明确授权、供应商/模型/金额选择与凭证配置。未获授权就保持待真实验收，不能宣布阶段 4 全部完成。

每个里程碑结束检查本周用量；依 2026-10-04 的新授权，剩余不高于 20% 就安全保存并暂停自动续做，不继续新开发。其他授权边界不变，不因下一周重置自行恢复。此计划不添加新的最终功能，不提前做 MCP/视频/部署。

## 执行闸门与不变量

- 模型与连接必须属于当前租户/项目，能力和报价在人工确认时冻结；确认后变更连接、参数或价格不能复用旧确认。
- 密钥只用服务端引用与受控凭证接口，不进入浏览器、画布、日志、账本或项目包。本轮不读取现有 `.env`、私人密钥或账号。
- 自定义地址需要 SSRF 防护、请求/响应大小限制和禁止盲目重定向；测试传输单独注入，不能为方便测试放松真实网络策略。
- 不自动换供应商/模型，不自动重试付费请求；不得沿用 SDK 的隐式重试。请求发送后的断网、超时和无法确认扣费都进入计费待核对，保留预留。
- 生成失败不等于未收费。返回损坏图片、资产保存失败或收据丢失时，产物与计费分别记录，不能因为没有图就自动释放预算。
- `usage` 缺失不记为零；明确区分供应商实报用量与带报价版本/来源的估算。跨币种不默认为 1:1，不使用浮点或临时汇率绕过已确认成本上限。
- 浏览器工作台的内部蒙版定义为“白色允许改、透明锁定”。每个供应商必须核对蒙版极性并测试转换；未核对不能直接转发内部蒙版。EXIF、尺寸、色彩与坐标变换也必须一致并可追溯。
- 商品像素锁定是产品承诺而不是提示词。真实编辑需要明确可验证的锁定区域，并通过输出检查/确定性合成保持锁区；只有文字“只改背景”而没有可靠区域依据时，不能承诺硬像素不变，应拒绝或要求补充约束。
