# 阶段 4 里程碑 2：官方图片协议的本地验收

日期：2026-10-03。范围是**纯协议请求构造、响应解析、测试专用假传输**。没有真实 OpenAI HTTP 传输、凭证读取或供应商账单验收；工作台仍只运行原有 mock。

## 官方资料对实现的影响

按 OpenAI Docs 工作流检索并实际打开[生成参考](https://developers.openai.com/api/reference/resources/images/methods/generate)、[编辑参考](https://developers.openai.com/api/reference/resources/images/methods/edit)和[图片指南](https://developers.openai.com/api/docs/guides/image-generation)。采用显式 `/images/generations` 和 `/images/edits`，没有改成聊天/Responses 工具。当前编辑参考的 JSON `images` 支持图片引用及 Data URL，最多 16 张；单个引用长度和本地总请求大小都独立受限。

模型始终由上层明确传入，不替用户选模型或价格。用量字段可缺失；即使返回 token 也不是已结算的货币费用。蒙版必须和底图尺寸、格式对应，并有 alpha 通道；模型仍只把蒙版当引导，不是商品硬像素锁定。内部极性转换通过本地像素测试，不能当作真实供应商行为已经验收。

## 实现

`apps/api/src/openaiImageProtocol.ts`：

- 先验证里程碑 1 的连接/参数合同及权威输入收据，再核对**实际原文件字节**的 SHA-256 与长度。不能用缩略图或已存收据代替文件。
- 顺序完整解码、应用 EXIF 方向、sRGB 归一化为 PNG；底图坐标与蒙版尺寸一致。记录原文件摘要、实际发送摘要、转换版本，以及完整负载摘要。
- 内部蒙版要求白色覆盖和 alpha；可编辑 alpha 转为透明覆盖，透明锁区转为不透明，保留抗锯齿覆盖。未知/不匹配的供应商极性、非白色标记和硬像素锁要求均拒绝。
- 发送合同固定 `n=1`，尺寸/质量/背景/格式均显式；输入保真和压缩只在已声明支持时添加。不构造鉴权头、不解析密钥引用、不拼供应商地址、不发请求、不重试。
- 本地请求上限 64 MiB，响应正文上限 32 MiB，候选产物上限 20 MiB。归一化后的单文件和累计大小重新检查；在创建更多 Data URL 前检查累计开销。图片引用还遵循当前官方 JSON 引用字符上限。
- 解析只接受 200/JSON、合法 UTF-8、单个输出、规范 Base64、请求格式与对应魔数。供应商图片 URL 永不自动下载，重复输出或已改变格式不能静默接受。
- 用量须为非负安全整数且总数一致；已知字段不合法时保持未知扣费。忽略无关新增元数据，不保存原始错误消息、私密文本或不合法请求编号。
- 成功解析的二进制只是 `pending-validation` 候选；**截断图片即使有正确魔数也还未验收**。阶段 4 里程碑 5 必须完整解码/核验尺寸及透明要求、持久化真实资产、保护锁区，再建立可信谱系。

## 本地假响应测试

`tests/helpers/local-image-protocol-session.ts` 只在测试中使用，不是生产 Worker：注入内存或回环假服务；同一任务/幂等键/确认摘要/负载并发或重复调用仅派发一次，超时/断线记录 `billing=unknown`，不自动再派发。迟到响应不覆盖已返回的未知状态。这里只证明测试流程，**生产持久化幂等、计费冻结和进程重启仍需任务内核整合**。

新增 17 项协议/回环 HTTP 测试覆盖生成/编辑、EXIF、蒙版极性与抗锯齿、文件变更/损坏、转换大小限制、缺用量、用量不合法、HTTP 4xx/5xx/重定向、坏 JSON/Base64/魔数、格式漂移、重复输出、超时/断线及并发重放。HTTP 整合只访问显式 `127.0.0.1` 临时服务，鉴权值是固定测试字符串；没有放松生产 HTTPS 或将私人凭证注入测试。

最终代码 `pnpm check` 通过：22 个测试文件、151 项单元/集成、6 个工作区构建、29 项 Chrome 回归。转换累计大小优化后全套重新跑过，不只沿用优化前结果。

## 尚未开放

没有供应商连接目录、可信凭证解析、真实网络传输与 SSRF/DNS/流式大小限制；解析正文上限不能替代网络接收时的有界读取。没有真实资产落库、费用结算、任务派发或画布供应商切换。`assertRealImageExecutionAllowed` 固定拒绝，`/health` 仍为 `contracts-only`、`realExecutorsEnabled=false`。

后续按原计划实现兼容中转差异配置、非 OpenAI 原生协议和安全回流；不得把本地协议通过宣称为阶段 4 整体完成或真实供应商验收。
