# 阶段 4 里程碑 5B2B2B：实际响应授权与资产/任务原子绑定

日期：2026-10-04（上海）。状态：**受控本地假响应路径已验收；里程碑 5 整体及真实供应商执行尚未完成**。本步骤接通 5A 的服务端执行授权，完成实际候选验证及资产/任务提交；没有真实网络、凭证、生产 Worker 或画布二进制回读。

## 授权来自持久化执行证据

`LocalImageTaskArtifacts.ingest(principal, jobId)` 是显式配置的服务端内部入口，只接身份和任务编号，不接调用者的候选、收据、确认时间或“已授权”标记。它与统一任务和资产服务必须共用同一个 SQLite 实例；日常桥接未配置产物/执行政策，新入口没有 HTTP 路由。

读取输入及处理候选之前，内核要求完整不可变确认、实际任务、原运行租约/实际领取人、派发意图、持久化尝试及 returned 原始响应对应。queued、not-connected 意图、attempted 写前记录及 interrupted 都不能单独授权入库。实际身份须为原尝试人，并具有当前 run:read/run:execute、provider:read、asset:write，编辑另需输入 asset:read。政策必须同步返回 undefined，布尔值或 Promise 均拒绝；缺失政策默认关闭。

服务读取有界原始包，按冻结的官方/兼容/Google 协议重新解析，核对原解析快照，不能覆盖响应或换协议/模型。事务外从实际原图重建负载，匹配已确认负载 SHA/长度/Content-Type 和输入转换记录。5A 的必填 authorizeCommit 在解码前、提交前核验服务端确认/响应与候选 SHA、原解析摘要；当前原图、约束及权限仍需匹配，异步期间漂移阻止提交。

这不是新的发送授权。已发送尝试的响应保存使用原确认时间和冻结连接，报价后来到期或当前目录停用不触发第二次发送，也不丢弃原有效响应；当前供应商/资产权限和原图/约束仍重新检查。原意图仍为 not-connected；attempted 不保证回调运行，只有实际保存的 returned 包支持处理本地候选，不能据此证明真实供应商接通。

## 同库原子提交与恢复

候选沿用 5A 完整静态解码和 MIME/尺寸/透明性验证，保存原始字节、不重新编码、不静默缩图。`onVerifiedCommit` 同步钩子在保存 BLOB/权威收据/谱系/存在标记/目录的同一事务内调用任务绑定；不得异步提交或使用另一数据库实例。

新的私有 ImageTaskArtifact 绑定确认、原尝试/响应、生成记录摘要、实际资产编号/文件 SHA、提交人和时间，任务 outputAssetIds 只指向已保存资产。提交端口另外核对数据库中真实生成记录和实际原包候选，不允许独立测试端口写入另一张有效图片后冒充任务结果。没有图片的任务不造占位编号。

图片、谱系、目录或任务保存后故障全部回滚这次产物，不回滚之前已提交的原响应与未知费用。回滚后尝试独立追加固定错误码/阶段的私有失败证据；权限撤销、损坏或容量不足时不强行写日志绕过政策。失败按阶段/代码去重，最多 16 项，不删除旧证据腾空间。

跨连接并发及重启重放复用同一资产；已绑定历史不重建负载、不重新解码或改变费用。恢复同时核对正文/收据/谱系/目录、私有任务记录、原响应、完整请求/协议/约束/转换/确认时间和审计；重新计算部分记录摘要也不能绕过关系校验。缺失或损坏失败关闭，不当作未生成而补发。具有本机管理权限者同时重写全部数据库与证据仍不在此安全边界内。

SQLite 继续使用 v5，不增加表或清空旧数据；私有任务快照只追加可选字段，旧 mock 精修、单位假价格、用户记录、商品锁、幂等语义与配置指纹不变。生成谱系单份限 512 KiB，与供应商修订/准备/原响应摘要及任务私有执行/意图/尝试/响应/产物/失败记录共用项目 16 MiB 额度；此额度不是全部应用数据库字节的硬上限。

## 产物与费用独立

好图、坏图和保存失败都不释放未知 maxCostMinor 预留；产物绑定不写费用账本或预算，不把估价或用量当成实费。原协议快照保持 pending-validation / billing=unknown，已验证资产状态另存，之后核账也不覆盖原包。

有图但未核账时任务仍 billing_unknown。只有现有人工核账/第二人超额审批提供证据后，有已验证产物的任务才为 succeeded；无产物则仍 failed。核账先完成后再明确恢复原响应产物，只更新产物/任务状态，不重结费用。超额批准不能提高项目预算，也不会自动发送。

执行器可显式注入同库产物处理器，仅在有效首次假传输返回后处理。产物错误在原响应事务之外处理，不能把已保存 returned 改成 interrupted。重放 started=false 不自动再处理或补发；故障后只可明确调用 ingest 处理既有原包，不自动重试供应商请求。

## 本机资源与界面边界

- 同进程产物处理并发 2，无无限排队；原图/输出/归一化仍共用两个完整解码槽。不是跨进程全局限制、生产沙箱或恶意文件隔离。
- 原包 32 MiB；输出 20 MiB、1600 万像素、单边 8192；原包/原图/生成图共用项目 512 MiB。4K 超限仍须发送前拦截，不先付费后缩图。
- pixel-exact 和 product.pixels 保持拒绝，protectionApplied=none；锁区保护未验收，不宣称商品硬像素保真。
- 工作台对已绑定图片显示“二进制回读尚未开放”，隐藏旧 mock“结果回到画布”和旧重试/执行入口；App 回流函数也拒绝把原生图片转成模拟节点。尚无供应商选择/准备/确认/生成图片预览 UI。
