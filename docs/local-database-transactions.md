# 本机任务数据库事务适配器

日期：2026-10-03。状态：阶段 3 第八里程碑，仍为零费用模拟。

## 实现与边界

本地工作台从单进程原子 JSON 改为 `SqliteRunKernel` / `SqliteRunKernelStateStore`。它们使用 Node.js 内建 `node:sqlite`，实测 Node 24.19.0 / SQLite 3.53.3；根项目声明相应 Node 版本要求。

生产路线的 PostgreSQL 不变。SQLite 仅是无需额外安装的本机事务适配器，不是生产 PostgreSQL 已上线，也不是把整个画布搬到数据库：画布及媒体仍在浏览器本地，数据库只保存模拟任务、预算、目录和证据。

## 一次操作的原子边界

1. 取得 `BEGIN IMMEDIATE` 写锁。
2. 检查执行策略指纹，读取最新状态及摘要。
3. 通过原合同、任务归属、幂等和金额守恒校验，构造临时内核。
4. 执行权限、输入、成本、租约或核账操作。
5. 将任务、预留、项目预算、账本、审计和审批完整聚合一次提交，随后才返回成功。

不长期缓存进程内余额。命令抛出未知异常、磁盘写入失败或提交失败时整体回滚；后续命令重新读取数据库，不会继续使用已经变动但未落盘的内存。明确的业务拒绝可以提交拒绝审计，但不能凭拒绝事件扣费。数据库锁竞争返回 `503 run_state_busy`，其他数据库错误返回 `503 run_state_unavailable`，浏览器保留原动作编号供重试，不自动重试付费任务。

目录新增与对应项目预算在同一外层事务中提交，嵌套事务用 SAVEPOINT；不允许异步返回，不在写锁中做模型、对象存储或 MCP 网络请求。未来执行器必须先提交领取/启动记录再执行外部请求，外部请求与数据库不可能具有同一个本地事务；响应丢失继续遵守未知计费与人工核账语义。

执行策略指纹包括假定价、最大并发、项目及供应商限流、执行租约和超时时间。其他服务不能通过更宽松的配置读取同一数据库。配置更新需要后续明确的版本迁移，不能直接改配置消除预算告警。

## 恢复与迁移

- 第一次初始化在一个事务中读取旧 `catalog.json` / `runs.json`，校验后写入数据库。旧单进程文件中运行未结束的任务保守地转为待核账，预留不释放。
- 旧文件原样保留，不删除、不覆盖。迁移完成后不再更新旧文件，不能将它们当成最新备份。
- 损坏 JSON 或不守恒记录使迁移整体回滚，不留下半个目录。数据库损坏、摘要不一致、已初始化状态行丢失、未来 schema 或预算配置漂移均拒绝，不退回旧文件、不静默清空。
- 数据库共享模式中，另一进程的运行任务可能仍在工作，重载不能直接标记为进程中断。未启动租约到期回队列；已启动租约到期转为未知计费，原预留保持冻结；系统不自动重试。
- 服务关闭释放数据库连接；测试专用目录关闭全部连接后清理，不使用用户工作台状态。

数据库开启 WAL 与 `synchronous=FULL`，采用全数据库单写者串行提交。数据库及其 WAL/SHM 文件需位于同一电脑的本地磁盘，不能放到网络共享盘。运行中的数据库不能只复制 `.sqlite` 单文件冒充一致备份；本轮尚未实现在线备份，应关闭全部服务连接后再做整目录备份。

## 验证证据

自动测试使用多个真实 Node 子进程及多个数据库连接，覆盖：

- 同动作同时创建只保留一个批次；重复确认不增加预留。
- 两个批次竞争项目余额，只有余额覆盖的批次冻结，拒绝审计不覆盖成功者。
- 多个进程领取同一输出，只产生一个有效租约；重复执行不重复结算。
- 不同项目共用供应商并发槽位。
- 同一审批同时重放，只发生一次财务结算，项目总额度不提高。
- 写入后抛错与确认提交前进程直接退出，不留下半份账本。
- 未过期运行任务不会因另一服务启动而进入未知计费。
- 锁竞争、坏摘要、丢失行、配置漂移、未来版本和非法异步事务拒绝。
- 旧文件完整迁移、损坏迁移回滚及多服务目录可见性。

## 仍未完成

- 数据采用合同聚合 JSON 行，不是规范化财务表；未提供 PostgreSQL 行锁、跨机器 Worker、生产队列或可扩展索引。
- 同步全局写锁和完整聚合校验适合小规模本机模拟，不是高吞吐生产服务。
- 目录仍来源于浏览器元数据登记，未验证真实图片字节、对象存储内容或供应商产物。
- 尚无真实多成员鉴权、付费调用、在线数据库备份和密钥服务。

下一步是权威资产校验；这些边界解除前不能将本机演示宣称为生产可用。
