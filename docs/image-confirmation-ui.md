# 阶段 4 里程碑 5B4B：完整人工冻结确认界面

日期：2026-10-04（上海）。状态：**5B4B 已通过本地验收**。本步骤只接完整人工核对、本地假报价确认和统一任务/上限预留事务，不调用供应商，不配置真实执行政策。里程碑 5、真实供应商和阶段 4 整体未完成。

## 可信完整人工摘要

公开准备单新增必填 `constraint`，直接来自服务端原不可变准备记录，不读取浏览器当前约束来补齐历史。原准备单摘要和数据库格式不改写；旧有效服务端记录已经保存完整约束，因此无需迁移或重报价。公开合同仍严格拒绝私有连接地址、端点、鉴权和凭证引用。

人工核对界面显示冻结供应商/协议/修订、模型/能力、完整设计指令、约束编号/时间、锁定路径、品牌规则、每个可编辑区域及蒙版编号、输出规格/数量、全部参数和中转受控参数。编辑原文件按实际冻结顺序展示编号、MIME、精确字节数、尺寸和 SHA；蒙版另列同样信息。名称可能变化，不用客户端现有名称冒充已冻结输入身份，不读取或展示本机文件路径/供应商 URL。

浏览器重新计算严格解析后完整人工约束的 SHA-256，与服务端请求模板内的约束摘要匹配；品牌/区域变化也不能只保留编号和原摘要蒙混通过。公开准备关系核对项目、约束、输出规格、连接修订、模型能力和假报价关系。完整准备摘要包含私有连接及其他冻结信息，浏览器将其作为服务端不透明摘要使用，不尝试从不完整公开字段重算并冒充整个快照。

假报价显示证据、编号/版本/来源、币种、整数最小币种单位的估价和预留上限、有效期。不是实际费用或汇率换算，不能编辑金额或默认以估价代替上限。每任务 n=1；不移除商品锁，不缩图或换模型绕过 1600 万像素限制。

## 人工确认和保守恢复

准备单原样保持 `unconfirmed / executionAuthorized=false / protocolPreparation=not-run`，确认结果是独立记录。人工须先核对确认历史，再明确勾选完整冻结设计/输入/币种/估价/上限，点击“确认假报价并预留上限”。不会自动勾选、自动 POST、生成或执行。修改当前选择/参数、目录漂移或报价过期阻断旧确认，要求新准备动作；历史恢复可以重新核对原冻结内容，不能把已改表单当成原确认。

确认 POST 仍只发送原完整准备摘要和期望币种/估价/上限；不接受客户端确认时间、任务编号、发送摘要、收据或执行许可。复用 5B2A 服务：服务端在协议准备前与同库事务提交前复查当前连接/能力、输入/约束、报价和权限。完整负载准备、真实服务端任务编号及不可变执行快照与按 maxCostMinor 的预留原子保存；重复只保存一次，不复用旧 mock 自动结算。

结果严格核对原准备编号/摘要、租户/项目、约束/适配器/工具、实际任务关系、币种/估价/上限、原确认时间，以及输入转换顺序/原 SHA/转换用途。确认时间属于原报价有效期；历史报价当前过期不抹除已有确认。历史上限可能经既有第二人超额审批提高，不误将当前批准上限当成原假报价。任何历史读取都不构成新执行许可。

确认前先保存只读恢复指针（版本、项目、准备编号和摘要，最大 16 KiB），无报价、设计指令、地址、凭证或授权。存储失败不 POST；响应丢失/错配/取消后状态未核对，按钮保持关闭，只能 GET 核对原结果，然后再由人决定。刷新、重开或项目切换只读原准备和确认；不补发确认、不重新预留。指针损坏/跨项目失败关闭，不静默覆盖。开始新动作只清除本项目浏览器准备/确认指针，服务端全部历史/任务/账本保留，不取消旧任务。指针不是正式多租户离线会话隔离。

确认结果固定 `local-fixture / confirmed-not-dispatchable / protocolPreparation=prepared / executionAuthorized=false / realExecutionEnabled=false`。显示实际批次/输出任务、确认人/时间、执行快照和已准备负载摘要；负载不是已发送证据。任务列表和预算按服务端结果更新，预算读取失败不撤销已成功确认或造零预留，不重新确认。旧 mock 执行/重试/自动核账/回画布仍与原生图片隔离；无画布结果回流。

## 只读确认历史接口

新增 `GET /v1/projects/:projectId/image-preparations/:id/confirmation`，需配置服务端确认内核、正确租户/项目、provider:read 与 run:read；无 run:confirm 也只能读取已有历史，不能创建确认。接触私有准备/任务前核对权限，返回前再次核对。匿名/跨范围/撤权拒绝，查询、正文、Range 和 POST 不接受，响应 no-store。

返回严格模式/准备编号/完整准备摘要及 nullable 公开确认。无确认返回 null，不制造任务；已有确认从完整原执行快照及统一任务守恒关系核验恢复。只读路径不用普通内核刷新命令，不恢复过期租约、不保存快照、不修改任务/账本或预留，也不重新估价、准备协议或发送。停用目录/过期报价/已取消任务可以恢复已存在历史，但不再预留；损坏失败关闭。本界面另行读取现有预算端点以显示预算，不将其当成确认或执行。

本机 SQLite 的完整 JSON 快照核验不是生产归一化数据库。确认 JSON 上限 512 KiB、4096 个非空分片、30 秒取消信号；超限整体失败关闭，保留原动作恢复指针，不截断审计历史。网络继续只走 runClient 固定同源/no-store/禁止重定向和本地标记。
