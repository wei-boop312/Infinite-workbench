# 6D3A 独立生产领取、租约检查与未启动到期恢复

日期：2026-10-04（上海）。范围：默认关闭的内部生产租约底座已通过完整本地验收；仅自有假价格端口、临时SQLite与4173。没有负载重建、派发意图、发送尝试、凭证消费、DNS/HTTPS调用、响应、产物授权或实际费用结算。本次不代表6D3整体、真实供应商或阶段4验收完成。

## 独立权限与权威政策

新增内部 `claimProductionImageBatch`、`inspectProductionImageLease`、`reconcileProductionImageBatch`，显式指定项目/批次；不是HTTP路由，不接日常桥接。没有 `productionImageLeasePolicy` 即在读取私有状态前拒绝。政策必须与内核共用同一实际SQLite存储实例，路径相同但连接实例不同也拒绝；不使用6D2B的临时pending创建证明或local-fixture租约政策。

`createProductionImageLeasePolicy()` 无配置拒绝；可信服务端须显式提供 `leasePreparationEnabled=true`、租户、同步run/provider/asset政策、同库、时钟及server-pricing端口。独立 `createProductionImageLeaseFixturePolicy` 只接受contract-fixture/realExecutionEnabled=false，不能将假端口或假依据改标为生产。端口和服务端配置属于可信代码，不是用户脚本沙箱。

私有任务/原准备/目录与原文件读取前，必须严格租户项目及run:read/run:execute/provider:read/asset:read全部同步true；Promise、非true和私密异常失败关闭。检查租约先核验实际任务、workerId、leaseId及历史实际领取人，其他有权限的人不能借用同一个worker字符串。逐份原文件核验前后复查范围，检查结束及SQL实际写后再次核验；权限撤销、原图/蒙版/约束/目录漂移、到期或保存故障回滚整个外层事务。

领取与活租约检查核对实际完整不可变生产确认及原准备、当前完整连接修订/模型能力、权威原图/蒙版SHA/精确尺寸/大小/顺序与原约束、实际任务/原编号和独立key、预留关系与预算币种。原价格依据的来源/版本/有效期/范围通过可信verify再次核验，purpose=lease；不重新read询价。价格scope仍绑定原创建人，不用工作执行人的身份替换原价格依据；价格或参数改变须新人工动作。原始输入与output边界及product.pixels/pixel-exact拒绝不变。

## 领取、限流和不可变历史

共用现有最大领取数量、项目并发、供应商并发及持久化时间窗，不创建第二本预算账或绕过旧mock/local占用。每个生产批次仍只有一个实际任务，领取只从queued进入leased，批次仍queued。maxCostMinor预留不变，known数值或unknown/null原样保留，不补0或上限、不自动结算。

同一事务保存实际job/worker/lease/领取人/领取时间/期限、完整确认指纹与job-leased审计。独立可选 `productionImageLeases` 为追加历史，和实际任务字段、审计、完整确认/原准备关系共同核验；schema或自报leased不能替代实际记录。不得生成batch-dispatched或job-started证据，领取不是派发、已发送或入库授权。重复/并发/跨SQLite连接或重启只领取一次，不重新预留；活租约的重复领取返回无新租约，原领取人可通过检查方法恢复既有租约。

历史最多512条、整体512KiB；历史和生产租约/到期审计计入现有共享16MiB逻辑元数据上限。不删除历史腾空间，容量不足不创建租约。纯只读快照核验期限正且不少于1秒，并严格核对所有绑定；实际内核恢复另匹配当前配置的期限，避免只读恢复将合法非默认期限误当30秒。SQLite仍v6，ICRD/v1不变；不是整个数据库/WAL/磁盘字节上限或生产归一化数据库。

## 到期与取消

生产租约不会被普通读取、构造内核、旧mock/local领取或恢复隐式重排。显式reconcile只处理leased且尚未启动的到期任务：追加原租约到期审计，清活租约字段并回queued，保留实际job/key、全部历史和max预留；不会产生响应、扣费结论或重发。再次领取必须重新通过当前价格/连接/权限及限流政策。

未发送到期恢复要求当前权限、完整原确认/准备/实际任务、权威输入/约束和预算关系，但不因原报价过期或目录停用而永久保留过期活绑定；它不调用price read/verify，也不构成新执行许可。恢复后旧租约检查拒绝，旧报价/连接不能重新领取。撤权/原图或约束损坏/容量不足/写后失败仍失败关闭，不强行丢证据。

未启动取消沿用统一run:cancel和原账本，按原上限释放且清zero-cap预留关系；保留租约历史。生产状态目前仅queued/leased/cancelled，拒绝旧执行/超时/重试/自动结算；没有running、providerRequestId、输出或真实费用。这个取消规则不能用于后续已经写意图/发送后的unknown计费。
