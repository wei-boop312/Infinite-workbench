# 阶段 4 里程碑 5B3A：有权限的生成资产二进制回读

日期：2026-10-04（上海）。状态：**本机只读回读已验收；浏览器原图缓存、画布结果回流和里程碑 5 整体尚未完成**。此步骤不发送供应商请求、不处理新产物，也不结算费用。

## 身份与只读边界

`LocalGeneratedAssetReads.read(principal, projectId, assetId)` 只接服务端身份和不透明编号，构造时明确配置租户、同一 SQLite 存储与资产权限端口。访问数据库快照、目录、原始协议包和图片之前，要求身份属于配置租户且目标项目的同步 `asset:read` 返回严格 `true`；Promise 不构成许可。返回前再次核验读取权限。越权、跨租户/项目及不存在的资产统一返回 404。

读取不要求 `run:execute`、`asset:write` 或 `provider:read`，也不取得这些能力。已保存图片不会因为报价后来过期或连接停用而丢弃；这不是新的发送授权。只读成员可取回已绑定产物，不需要重新读取编辑输入。独立 5A 入库但未绑定实际任务的资产不通过这个端点读取。

`InMemoryRunKernel.assertSnapshot` 复用完整确认、租约、意图、尝试、响应、产物、审计及账本关系检查，但明确跳过恢复时的过期租约处理、状态刷新和保存。读取在一致事务中进行，不调用可恢复/写入的任务命令包装器；旧默认恢复语义不变。费用未知仍保留 maxCostMinor，已核账费用不重结；读取不会触发发送、产物恢复、预算释放或另一个项目的租约恢复。

## 实际字节与证据关系

读取同时核验以下既有证据，不接受浏览器自报收据：

- 实际任务的完整不可变确认、原租约/尝试/returned 响应、产物编号和审计。
- 生成记录/存在标记/权威收据、完整请求/约束/协议/转换/确认时间及原响应关系；与任务恢复共用 `imageArtifactIntegrity.ts`，不能只重算部分摘要绕过绑定。
- 数据库中的原准备单与已确认冻结准备单完全一致，资产目录元数据与权威收据一致。
- 原始协议包的正文/标记/摘要，按冻结的官方、兼容或 Google 原生协议重新解析；实际候选 SHA、长度和 MIME 必须对应保存的图片。
- 保存的原始图片 BLOB 的 SHA、收据、格式魔数和既有输出容量政策。返回独立字节，不能修改服务端持久内容。

返回仅包含原文件、受控 MIME 和 SHA，不暴露完整谱系、提示词、报价、地址或凭证引用。此前入库已做完整静态解码，此回读校验原始字节和不可变证据，不重复解码、重编码或缩图。只查数据库，不解析客户端文件路径、对象路径或供应商 URL，不访问外网。

SQLite 继续 v5，无迁移或新表。当前任务仍保存在单份 JSON 快照中，只读核验会检查整份快照；无关任务关系损坏也可能令本次读取失败关闭，不是生产归一化数据库或跨进程资源隔离。底层只读取目标图片的 BLOB。具有本机管理权限者同时重写全部证据不在安全边界内。

## HTTP 合同

`GET /v1/projects/:projectId/generated-assets/:assetId/content`

API 必须显式注入读取端口，否则 503；未认证 401。只允许 GET，HEAD/POST 等返回 405，拒绝所有查询参数、请求正文及分段传输；Range 返回 416，不提供部分字节。损坏或无法完整核验返回固定 503 错误码，不返回私有异常文字，不重新生成。条件请求不绕过认证/完整核验，也不以 304 返回租户资产。

成功响应为原始 PNG/JPEG/WebP 字节，明确 `Content-Type`、`Content-Length`、`X-Content-SHA256`、`X-Canvas-Binary-Version: generated-image-v1`、`Cache-Control: private, no-store`、`Vary: Authorization`、nosniff、same-origin CORP、no-referrer 和沙箱 CSP；无可复用签名 URL、重定向或跨域放行。服务端响应层再次复制、复算 SHA 并核验魔数/长度，不盲信可注入的端口。错误响应同样 private/no-store。

HTTP 响应同进程最多 2 份，没有无限排队；槽位在服务端 finish 或 close 释放，响应设置 30 秒空闲超时。此限制是响应生命周期的本机防护，不是客户端确认送达、分布式并发上限或生产沙箱。单份输出仍限 20 MiB、1600 万像素、单边 8192；项目 512 MiB 二进制/16 MiB 图片元数据政策及 4K、pixel-exact/product.pixels 拒绝规则不变。

日常本地桥接只启用这个只读服务，沿用回环、同源和本地请求标记与现有项目角色。`generatedAssetReadEnabled=true` 仅说明读取端口存在，`realExecutorsEnabled=false` 保持不变。默认目录为空，未配置执行/产物政策，内部执行、原响应和入库仍无 HTTP 路由。桥接身份是本机模拟角色，不是已完成生产会话认证。
