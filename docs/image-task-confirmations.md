# 阶段 4 里程碑 5B2A：图片确认与统一任务原子保存

日期：2026-10-04（上海）。状态：**5B2A 已通过本地验收**，范围为 5B2 的确认、预留及任务快照部分。尚无图片租约执行、发送、产物授权或费用结算；未读取凭证、调用供应商或选择用户付费模型。

## 隔离旧模拟精修

统一任务内核新增可信服务端 `stageConfirmedImageBatch` 原子保存原语，必须与供应商服务共用同一 SQLite 存储实例。通用创建合同仍只接受旧商品精修，新图片任务只能通过受权限保护的准备单确认服务创建。

公开任务工具区分 product-retouch、image-generate 和 image-edit。新任务没有 mock 场景，不复用其自动成功、已知收费失败、超时释放或假输出编号。旧请求幂等摘要、商品锁校验、单位假定价和配置指纹保持原样。

图片任务当前仅支持 queued / cancelled；恢复时核对完整执行快照、任务归属、费用守恒及关闭闸门。旧通用确认、领取、派发、执行、超时检查和重试入口返回 image_execution_not_configured，不释放预留。仅从未执行的 queued 任务可人工取消；这不放松未知扣费的禁止取消规则。

## 确认与准备

`POST /v1/projects/:projectId/image-preparations/:id/confirm` 请求体不超过 16 KiB，只接受：

- expectedSnapshotFingerprint：准备单完整冻结摘要。
- expectedEstimatedCostMinor、expectedMaxCostMinor、expectedCurrency：估价、上限及币种。

客户端不能自报任务编号、执行幂等键、确认时间、执行授权、发送摘要、报价、收据、地址或密钥。确认需 provider:read、run:create、run:confirm、run:read；编辑另需 asset:read。桥接沿用回环、同源和本地标记；不是生产多成员鉴权。

服务端重新核对当前连接完整修订、能力、权威原图/收据、约束和报价有效期。先生成真实任务编号与独立执行幂等键，再运行已有官方、兼容或 Google 原生纯协议构造。编辑完整解码、EXIF/sRGB/PNG 归一化，记录原始/传输摘要及蒙版转换版本。multipart 边界使用实际任务指纹，不用准备单或占位编号代替。

异步准备期间不持有写锁。完成后在 BEGIN IMMEDIATE 中重查权限、连接、输入、约束及有效期，原子保存准备单原快照、实际请求、参数/报价、确认人/时间、任务、预留、账本与审计。冻结已准备负载的 SHA-256、字节数、Content-Type、协议和转换版本；**这不是已经发送的证据**。

负载字节不复制进任务快照。未来发送必须从不可变输入重建并匹配摘要和转换，再校验当前政策与租约。未创建网络传输、读取凭证或持有数据库事务 await。

## 预算、重放与公开边界

新图片路径按确认上限 maxCostMinor 预留，估价仍是估价，整数金额且币种匹配项目预算；没有修改旧假单价或建立第二套账本。同准备单跨连接并发仅保存一份任务/预留；不同准备单由统一事务预算守恒。写入后或响应回读前故障整笔回滚，保留原准备单编号恢复。

原准备记录不可变，仍为 unconfirmed / executionAuthorized=false / protocolPreparation=not-run。确认响应是独立 local-fixture / confirmed-not-dispatchable / protocolPreparation=prepared / executionAuthorized=false / realExecutionEnabled=false 记录。确认和 queued 状态不授权 5A 入库。

已确认、后来过期或取消的重放恢复原任务，不重新估价/预留/执行，原确认人/时间不变；首次确认必须检查当前有效性。记录缺失、损坏或漂移不能当作“没有记录”重新生成。

公开确认响应/任务列表不含 Base URL、凭证引用、私有文件路径或负载字节，全部 no-store。默认空目录、无 HTTP 配置写入或自动种入模型；有确认内核时健康状态为 catalog-preparations-staged-confirmations，旧目录服务未配置时仍 catalog-and-preparations-only。真实执行恒 false。

## 资源与画布

每进程最多准备两份确认，第三份返回 429，不排无限队列。协议归一化和原图/输出核验共用两个完整解码槽，保留像素/尺寸/超时限制；不是跨进程全局闸门或隔离沙箱。目录历史、准备单及执行快照共用默认每项目 16 MiB 元数据额度，每份记录不超过 512 KiB，不删除历史腾空间。

输出 20 MiB、1600 万像素、单边 8192 在准备/确认复查，4096×4096 不接受。锁区未验收，pixel-exact / product.pixels 保持拒绝，不放松旧精修保护。

画布只增加恢复图片任务时的“未接通”提示、预留上限显示并隐藏旧模拟执行按钮；尚无供应商选择/准备/确认 UI。新增 Chrome 图片任务合同夹具只验证显示/按钮隔离，后端原子确认另有真实本地 HTTP/SQLite 测试，不冒充完整生成 UI 验收。
