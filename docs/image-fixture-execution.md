# 阶段 4 里程碑 5B2B2A：持久化本地假传输与响应证据

日期：2026-10-04（上海）。状态：**5B2B2A 已通过本地零费用验收，5B2B2/5B2B/里程碑 5 整体未完成**。本步骤只完成执行尝试、原始响应和任务未知费用的持久化；没有实际产物授权、生成资产/任务原子绑定或画布结果回流。

## 显式内部测试路径

LocalFixtureImageExecutor 必须注入 mode=local-fixture、realExecutionEnabled=false 的可信本地测试传输；无默认传输、真实网络实现、凭证查找或新 HTTP 路由。日常开发桥接不配置图片执行政策，目录默认空，旧公开执行接口继续拒绝原生图片任务。测试回调是可信服务端代码，不是供用户运行任意代码的接口；模式标记不是恶意代码沙箱。

执行器与租约服务和统一任务内核共用同一 SQLite 实例。先按 5B2B1 检查实际领取人、workerId/leaseId、读取/执行/供应商/资产权限、当前连接/原图/约束/报价，事务外重建三个协议的负载，再匹配不可变确认中的请求/负载/转换摘要并原子启动。发送前再次完整检查并持久化尝试。异步准备、假传输和等待均不持有 SQLite 写锁。

传输仅收到 POST、协议路径、Content-Type 和独立负载字节，不收到完整地址、连接配置、鉴权计划或凭证引用。官方、兼容 multipart/JSON 与 Google 原生解析仍各用冻结协议，不静默改协议/模型。真实网络/SSRF、可信报价和 Google 真实接受行为均未验收。

## 意图、尝试和返回不得混淆

原 ImageDispatchIntent 永久保持 transport=not-connected，不覆盖旧历史。新 ImageFixtureAttempt 在调用测试传输**之前**单独提交，绑定确认快照、任务/批次、意图、实际领取人/执行器/租约、冻结负载 SHA 和时间。status=attempted 仅表示写前尝试记录，**不保证回调已经运行，更不表示真实供应商接受请求**。

只有有效首次启动的活续接才能调用一次假传输；重放返回 started=false，不暴露私有负载或重新解码。仅有旧意图、尝试后崩溃、超时、重启、报价过期、目录停用或响应保存故障都不能盲目补发。底层内部端口只供可信服务端使用，没有客户端已确认/已发送标记或公开续发令牌。

返回证据分 returned 与 interrupted，严格限定本地模式及字段。returned 保存实际原始包的状态、受控头字段、字节数/SHA、收到时间及对应协议解析快照；其中 providerStatus=returned、artifactStatus=pending-validation **不是成功资产**。HTTP 错误或坏 JSON 也可保存原始包及失败解析。超时、传输异常、非法/超限包、保存失败只记录固定代码，不把任意异常文字写入状态。

SQLite v5 增量追加响应 BLOB 表和独立存在标记，保留 v1–v4 原图、准备/确认、账本、未知费用与预留；未知更高版本拒绝。SQLite 提交端口自身要求 returned 携带正文，原始 BLOB/摘要/标记与任务响应证据、审计、未知费用账本在同一事务保存；忘记外层事务也不能留下半响应。完全一致重放复用证据，冲突不能覆盖；正文、行、标记或私有快照损坏时恢复失败关闭，不把丢失当作未执行。

原始响应仅服务端内部按租户/项目/任务读取并核对 SHA，每次回读返回独立字节。公开批次不包含响应正文、候选 Base64、私有连接或凭证引用。**尚无有权限的公共二进制回读/画布缓存路由**。

## 费用及恢复

无论返回好图、坏图、HTTP 错误、缺用量、超时、迟到响应或存储故障，扣费均 unknown，保留 maxCostMinor 而非估价。返回时将运行任务与未知账本原子绑定；已被到期核对为 unknown 的任务不重复追加未知账本。实际输出编号仍为空，未写生成资产或目录占位。

响应晚于报价/租约有效期仍可保存当次尝试的原始证据，不重新付费或确认。发送前有效性和响应保存是不同判断；权限撤销或无法保存中断证据时保留原意图/尝试及预留，之后由有权限的核对或到期恢复保守进入 unknown，不能强行自报免费。

人工核账沿用统一账本及第二人超额审批，不修改原响应快照；没有资产时核账后仍为 failed，不自动重试。保存故障完整回滚原始包/返回证据/账本，再尝试单独追加中断证据；若连中断证据也失败，不删除历史、不释放或重复发送。

## 本机容量边界

- 原始协议包限 32 MiB；输出候选仍限 20 MiB、1600 万像素、单边 8192。接收原始包不是完整输出解码。本步骤测试中的 1×1 响应不能代替请求 1024×1024 的有效产物。
- 原始包、权威原图和生成图共用每项目默认 512 MiB 二进制上限；已有原图/生成图入口也计入原始包，不删除历史腾空间。
- 目录/准备单/执行快照/意图/尝试/响应摘要共用默认 16 MiB 元数据额度，单份 512 KiB；响应摘要在 SQLite 与任务快照的两份存储都计入容量。
- 同进程两份派发准备/本地等待，超额失败而非无界排队；等待默认 5 秒、配置最多 30 秒，超时发出 AbortSignal，迟到完成不能覆盖已保存中断证据。输入归一化仍共用两个完整解码槽。
- 本机恢复会重读并核验私有原始包，有项目容量上限但不是生产归一化数据库、跨进程全局资源闸门或恶意文件隔离。4K 超限及 pixel-exact/product.pixels 拒绝政策不变。
