# 阶段 4 里程碑 5B3B：浏览器生成原文件缓存

日期：2026-10-04（上海）。状态：**本地受控下载/原图与代理缓存已验收；供应商选择、参数报价确认、任务结果画布回流及里程碑 5 整体尚未完成**。浏览器缓存不是生成权限、入库收据或计费结论。

## 两个既有读取端点

点击原生图片任务的“缓存输出 N 原图”，只读取实际 outputAssetId，不执行旧 mock 派发或回画布逻辑。`StudioRunClient.cacheImage` 按需加载缓存模块，网络仍统一经过 `runClient.ts` 的唯一 fetch 边界；既有网络隔离测试不放宽。

1. GET `/v1/projects/:projectId/assets/:assetId/verification`：沿用已有认证/asset:read 接口取得服务端不可变图片收据。
2. GET `/v1/projects/:projectId/generated-assets/:assetId/content`：沿用 5B3A，重新核验实际任务、生成记录、原包/候选及原字节关系；第一步收据本身不能绕过第二步实际任务授权。

路径只由编码后的项目/资产编号构造，固定 /studio-api 同源入口。请求 GET、same-origin 凭证与模式、no-store、禁止重定向、no-referrer、本地标记；不携带供应商地址/密钥，不保存令牌。拒绝非 200、重定向或缺 no-store，不自动重试或用旧缓存假装当前权限有效。

收据按既有严格 VerifiedImageSchema 解析；浏览器当前明确限定 local-studio 租户，而非通用生产身份系统。要求项目、资产、generated 用途、静态 PNG/JPEG/WebP、尺寸和容量政策匹配。原文件要求协议版本 generated-image-v1、精确 Content-Type/Content-Length/X-Content-SHA256，不接受内容编码；读完重新核对实际长度和 SHA，才交给本地资产库。

正文流收据最多 32 KiB、原图最多收据声明值且不超过 20 MiB；最多 4096 个非空分片，拒绝空分片与超额对象增长。每页缓存操作最多两份，覆盖下载至保存，没有无界排队。30 秒取消信号用于网络/流等待，关闭面板或切换项目也取消；浏览器原生图片解码并非可强制终止的隔离沙箱，完成后/提交前仍检查信号。

## 服务端元数据和本地派生数据分开

资产库保持服务端 assetId、创建时间、原始名称、来源、SHA、实际尺寸和元数据原样，包括不透明 local-verified 存储键。此键不是浏览器/文件系统路径；本地 BLOB 始终通过 assetId+role 查询，不跟随它访问外网或磁盘。

本地原图和 WebP 小代理另外保存，不把 indexeddb 缩略图路径、临时 URL 或浏览器时间覆盖到不可变服务端资产元数据。否则后续 /context 登记会被当成覆盖已存在资产。App 为 generated 图片优先读本地代理，缺代理时可用原图；代理占用仍计入 usage。项目包保存完整原文件，生成资产没有服务端代理索引时不打包这一可重新派生的代理；导入独立副本沿用原有 assetId 重映射，不伪造新的服务端生成授权。来源不在项目中的断裂引用仍由原项目包合同拒绝，不能静默抹掉谱系。

IndexedDB 增量 v2→v3，只追加 generatedCaches；不重建/清空旧 assets、blobs 或索引。新本地标记绑定租户、项目、assetId、完整元数据和 SHA，不保存完整私有谱系/连接/提示词。全库 assetId 仍唯一；编号对应别的项目、元数据不同、标记缺失/冲突时拒绝，不覆盖或按内容合并。两个独立输出即使 SHA 相同也保留两个资产编号。

图片 SHA/MIME、实际浏览器解码尺寸与收据匹配后，一次 readwrite 事务提交原元数据、原文件、代理和标记。写入/配额错误或提交前取消全部回滚，本次不留下半条资产；取消发生在已完成提交之后不删除已保存用户文件。并发一致重放复用同一编号，可重新保存同一原图及派生代理，不把已有本地标记当作服务器权限。已有良好缓存遇到下载拒绝不会被私自清除，但也不被当作这次动作成功或新授权。

移除资产同时移除本地缓存标记。原有备份恢复生成原文件保留不可变元数据；重新导入相同内容作为 source 时不把 generated 资产误复用成 source，避免通过旧导入入口生成未验收的任务结果节点。缓存没有写任务/账本/预算端口，不注册伪产物、核账、释放预留或发送供应商请求。

## 界面边界

缓存成功只更新当前项目资产库，可预览原文件的本地代理；原生任务的未知计费提示和核账入口保留，旧 mock 执行/重试/回画布仍隔离。缓存操作不刷新任务列表或预算以免触发任务恢复副作用。App、资产库和任务面板尚不允许 generated 结果回画布，后续应先做任务结果谱系与撤销/刷新关系，不能借普通添加资产绕过。

不改画布数据模型，不把 Base64、临时对象 URL、供应商 URL 或授权令牌写进画布。预览对象 URL 只在内存并沿用既有释放机制。Service Worker 继续绕过 /studio-api 与 /v1/，显式私有 IndexedDB 原文件保存与共享 HTTP/SW 缓存不是同一件事。已经授权下载的本机文件可离线保留，不宣称服务端撤权能远程销毁本地副本；真实成员会话/多租户离线隔离尚未验收。
